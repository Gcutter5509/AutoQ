# 👥 AutoQ — Сервис очереди и регистрации имён

Веб-приложение для онлайн-записи и отображения списка участников в порядке очереди с автоматической очисткой базы данных по расписанию.

---

## ⚡ Особенности

- ✍️ **Простая регистрация**: ввод имени и мгновенное сохранение.
- 🔢 **Строгий порядок очереди**: нумерация (`#1`, `#2`, `#3`...) и фиксация времени записи.
- 🔄 **Автообновление для всех пользователей**: новые имена появляются у всех без перезагрузки страницы (каждые 2.5 сек).
- 🕒 **Автоматическая очистка по расписанию**:
  - Дни: **каждый понедельник, среду и пятницу в 14:00 (UTC+5)**.
  - Очередь сбрасывается, счётчик начинается заново с `#1`.
  - Двухуровневая защита: фоновый планировщик + проверка при запросах (гарантирует очистку даже при перезапуске сервера).
- 🛡️ **Безопасность**: защита от XSS-инъекций, валидация длины имени, `.gitignore` исключает утечку базы данных на GitHub.
- 🐳 **Готовность к продакшену**: настроены `Procfile`, `Dockerfile`, `docker-compose.yml`, WSGI (Gunicorn) и GitHub Actions CI.

## 🌐 Публичный доступ: как выложить в интернет

> [!IMPORTANT]
> **GitHub Pages** предназначен исключительно для *статических* файлов (HTML/CSS/JS). Серверный код (Python/Flask) и базу данных (SQLite) GitHub Pages запускать не может.
> 
> **Стандартный и удобный путь**:
> 1. Вы загружаете этот репозиторий на **GitHub**.
> 2. Подключаете репозиторий к любому бесплатному хостингу (например, **Render.com**, **Railway** или **PythonAnywhere**), и сайт становится доступен по публичной ссылке в интернете (`https://ваше-имя.onrender.com`).

---

### Шаг 1: Загрузка проекта на GitHub

1. Зайдите на [github.com](https://github.com) и создайте новый репозиторий (например, `autoQ`).
2. В папке проекта на вашем компьютере выполните команды в PowerShell / Терминале:

```powershell
# Инициализация git
git init

# Добавление файлов в коммит (база данных .db автоматически игнорируется через .gitignore)
git add .
git commit -m "Initial commit: AutoQ queue site"

# Привязка к вашему репозиторию на GitHub (замените ссылку на свою)
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/autoQ.git
git push -u origin main
```

---

### Шаг 2: Бесплатный запуск в интернете

#### Вариант А: Render.com (Рекомендуется — бесплатно и быстро)
1. Зарегистрируйтесь на [render.com](https://render.com) через ваш GitHub-аккаунт.
2. Нажмите **New +** ➔ **Web Service**.
3. Выберите ваш репозиторий `autoQ`.
4. Render автоматически определит настройки:
   - **Environment**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `gunicorn --workers 1 --threads 4 app:app`
5. Нажмите **Deploy Web Service**.
6. Через 1–2 минуты вы получите общедоступную ссылку вида `https://autoq-xxxx.onrender.com`, которой можно делиться со всеми!

#### Вариант Б: PythonAnywhere
1. Зарегистрируйтесь на [pythonanywhere.com](https://www.pythonanywhere.com).
2. В разделе **Web** создайте новое Flask-приложение на Python 3.12.
3. Склонируйте репозиторий с GitHub через Bash-консоль.
4. Укажите путь к `app.py`.

#### Вариант В: Свой VPS / Сервер через Docker
```bash
docker compose up -d --build
```
Сайт сразу запустится на порту `5000` с сохранением базы в папку `./data`.

## 💻 Локальный запуск на компьютере

### Запуск в 1 клик на Windows
Просто запустите файл **`start.bat`**. Он сам запустит сервер и откроет сайт в браузере.

### Ручной запуск
```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск приложения
py app.py
```
Сайт откроется на [http://localhost:5000](http://localhost:5000).
