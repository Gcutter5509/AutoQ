# 👥 AutoQ

Сайт для моих суперкрутых одногруппников для создания очереди на сдачу работ

## ✨ Возможности

- 📝 **Выбор места в очереди**: пользователь вводит своё имя и выбирает одно из 15 мест в очереди (сетка из 3 рядов по 5 кнопок).
- 🔒 **Защита от повторной записи с устройства**: с одного устройства физически нельзя занять более одного места в очереди. При необходимости своё место можно освободить и выбрать другое.
- 🔢 **Итоговый упорядоченный список**: отображение участников строго по порядку занятых мест (`№ 1`, `№ 2`, ... `№ 15`) с фиксацией времени записи.
- 🔄 **Реальное время**: автоматическое обновление сетки кнопок и списка каждые 2.5 секунды у всех пользователей без перезагрузки.
- 🕒 **Автоочистка по расписанию**:
  - База данных обнуляется **каждый понедельник, среду и пятницу в 14:00 (UTC+5)**.
  - Все места освобождаются, и очередь открывается заново.
  - Двухуровневая защита: фоновый планировщик + проверка при запросах.

## 🚀 Запуск проекта

### Локально
Запустите файл **`start.bat`** (Windows) или выполните в терминале:

```bash
pip install -r requirements.txt
py app.py
```
Сайт будет доступен по адресу: [http://localhost:5000](http://localhost:5000)

### Через Docker
```bash
docker compose up -d
```

### Облачный деплой (Render / Railway)
В проекте подготовлен `Procfile`:
```
web: node server.js
```

**Обязательные переменные окружения в панели хостинга (Environment Variables):**
- `TURSO_DATABASE_URL` — ссылка на базу данных Turso (например, `libsql://your-db-username.turso.io`)
- `TURSO_AUTH_TOKEN` — токен авторизации Turso
- `PORT` — обычно назначается платформой автоматически
