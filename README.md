# 👥 AutoQ

Простой веб-сервис для записи имён и отображения очереди участников в реальном времени с автоматической очисткой базы данных по расписанию.

## ✨ Возможности

- 📝 **Онлайн-запись**: ввод имени и мгновенное добавление в очередь.
- 🔢 **Порядок очереди**: отображение записей строго в порядке ввода (`#1`, `#2`, `#3`...) с фиксацией времени.
- 🔄 **Реальное время**: автоматическое обновление списка каждые 2.5 секунды у всех пользователей без перезагрузки.
- 🕒 **Автоочистка по расписанию**:
  - База данных обнуляется **каждый понедельник, среду и пятницу в 14:00 (UTC+5)**.
  - Счётчик очереди сбрасывается и начинается заново с `#1`.
  - Двухуровневая защита: фоновый планировщик + проверка при запросах (гарантирует очистку даже при перезапуске сервера).

## 🚀 Запуск проекта

### Локально
Запустите файл **`start.bat`** (Windows) или выполните в терминале:

```bash
pip install -r requirements.txt
py app.py
```
Сайт будет доступен по адресу: [http://localhost:5000](http://localhost:5000)

### Через Docker
```bash
docker compose up -d
```

### Облачный деплой (Render / Railway)
В проекте подготовлен `Procfile`:
```
web: gunicorn --workers 1 --threads 4 app:app
```
При подключении репозитория сервис развернётся автоматически.
